在 [Faro 控制台](https://faroapi.com/console) 查看当前公告和官方联系方式。群链接可能变化，以站内公布的入口为准。

## 复制这份模板

```text
使用工具和版本：
电脑系统：Windows / macOS / Linux
发生时间（含时区）：
模型完整名称：
使用协议：Responses / Chat Completions / Anthropic / 不确定
Base URL（不要附带密钥）：
完整错误文字：
新建空对话、发送一句短话是否也失败：
Faro 对应日志是否有记录：
```

截图尽量保留时间、模型和报错区域。隐藏 API Key、Cookie、邮箱、付款账户和无关聊天内容。公开群里不要发送完整配置文件。

## 充值问题

通过官方私聊渠道提供订单号、支付时间、金额以及账单状态。不要把支付密码、验证码或银行卡信息发给任何人。没有确认到账前，不要反复补付同一笔订单。

## 教程和界面不一样

提供软件版本号和设置页截图即可。CC Switch、Codex++ 与官方客户端更新较快；相同功能可能换了位置，不能为了对上截图随便降级或删除配置。
