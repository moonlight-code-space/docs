在 [Faro 控制台](https://faroapi.com/console) 的 **API 信息** 或公告里找到官方交流群。

## 复制这几行发给客服

```text
我用的软件：Codex++ / CC Switch
要配置的工具：Codex / Claude Code
电脑系统：Windows / Mac
使用的模型名字：
卡在哪一步：填地址 / 获取模型 / 保存使用 / 发消息
发生时间：
报错文字或截图：
```

截图前隐藏 **API Key**，也不要发送登录密码或整个配置文件。界面和教程不一样时，再补一张设置页截图和软件版本即可。

## 充值后没到账

先刷新 [钱包](https://faroapi.com/console/topup)。还没到账，就通过官方私聊提供订单号、付款时间和金额。不要重复支付，也不要发送支付密码、验证码。
