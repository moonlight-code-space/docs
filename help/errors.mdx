## 获取不到模型

先检查这三项：

1. **地址**：Codex / Codex++ 填 `https://faroapi.com/v1`；Claude Code 填 `https://faroapi.com/`。
2. **密钥**：从 Faro 令牌管理重新复制，别填成登录密码。
3. **令牌状态**：确认没有过期、停用，或限制了你要用的模型。

再获取一次。仍失败时，可以从 [模型广场](https://faroapi.com/pricing) 复制完整模型名填写；如果还是不能用，把报错发给 [客服](/help/contact)。

## 有模型列表，但发不了消息

确认已点 **启用 / 使用**，再重新打开工具、**新建对话**。

核对模型完整名字和适用工具。不确定时，把模型名字和报错发给客服。

## 常见提示

| 看到的提示 | 先做什么 |
| --- | --- |
| 密钥无效 / 401 | 检查密钥是否复制完整、令牌是否可用 |
| 余额或额度不足 | 查看 [钱包余额和令牌额度](/account/wallet) |
| 找不到模型 / 404 | 对照上面的地址，重新选择模型广场里的完整名字 |
| 被限制 / 403 | 不要反复重试，把软件名称、模型和报错发给客服 |
| 请求太多 / 429 | 先暂停其他任务，等一会儿再试 |
| 一直转圈，或 500 / 502 / 503 / 504 | 看 [模型监控](https://faroapi.com/about)，保留报错和发生时间，联系支持 |

还是解决不了？直接用 [反馈模板](/help/contact)，不要发密钥。
