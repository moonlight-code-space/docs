还没安装？先看 [下载与打开工具](/start/install-tools)。

## 1. 添加 Faro，填地址和密钥

打开 CC Switch，选择你要用的 **Codex** 或 **Claude Code**，点击 **+ → 自定义**，名称填 `Faro API`。

<Tabs>
  <Tab title="Codex">
    | 字段 | 填什么 |
    | --- | --- |
    | API 请求地址 | `https://faroapi.com/v1` |
    | API Key | 从 Faro 令牌管理复制的密钥 |

    其他选项先保持默认。若出现 **上游格式**，选择 **Responses（原生）**；**使用完整 URL** 保持关闭。

    <Accordion title="查看填写示例图">
      CC Switch v3.20.2 字段示意，非实机截图。

    </Accordion>
  </Tab>
  <Tab title="Claude Code">
    | 字段 | 填什么 |
    | --- | --- |
    | 请求地址 | `https://faroapi.com/` |
    | API Key | 从 Faro 令牌管理复制的密钥 |

    其他选项先保持默认。若出现 **上游格式**，选择 **Anthropic Messages（原生）**；**使用完整 URL** 保持关闭。

    <Accordion title="查看填写示例图">

    </Accordion>
  </Tab>
</Tabs>

## 2. 获取模型，选中要用的名字

点击 **获取模型列表**。

打开 [模型广场](https://faroapi.com/pricing)，选择适用于 Codex 或 Claude Code 的模型，再回到列表选中**相同的完整名字**。

没有获取按钮时，直接复制模型广场中的完整名字填写。

## 3. 保存，再启用

点 **添加 / 保存**，回到 Faro 卡片点 **启用**。

重新打开 Codex / Claude Code，**新建对话**即可使用。

获取失败或保存后不能用？看 [常见问题](/help/errors)。
