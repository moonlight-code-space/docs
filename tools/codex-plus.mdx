打开 **Codex++ 管理工具**。还没安装？看 [下载与打开工具](/start/install-tools)。

## 1. 添加 Faro，填地址和密钥

进入 **供应商配置 → 添加供应商**。如果有 **启用供应商配置切换** 总开关，先打开。

本页配置的是 **Codex（GPT）**，使用带 `/v1` 的地址。

| 字段 | 填什么 |
| --- | --- |
| 名称 | `Faro API` |
| 接入模式 | **纯 API** |
| Base URL | `https://faroapi.com/v1` |
| Key | 从 Faro 令牌管理复制的密钥 |

**无需认证** 保持关闭，**上游协议** 选 **Responses API**。其他选项先不用改。

## 2. 获取模型，选中要用的名字

点击 **从上游获取**。

打开 [模型广场](https://faroapi.com/pricing)，选择供 Codex 使用的模型，回到列表选中**相同的完整名字**，设为 **默认模型**。

没有获取按钮时，直接复制模型广场中的完整名字填写。

## 3. 保存，并使用 Faro

点 **保存**，再点 Faro 卡片上的 **使用**。如果你在详情页，按钮叫 **设为当前**。

## 4. 打开 Codex，开始使用

退出原来的桌面应用，回到管理工具的 **概览 → 启动 Codex++**。

**新建对话**即可使用。

用不了？看 [常见问题](/help/errors)。
