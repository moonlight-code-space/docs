先打开 **Codex++ 管理工具**，不是直接打开聊天窗口。还没安装？看 [下载与打开工具](/start/install-tools)。

## 1. 添加 Faro，填地址和密钥

进入 **供应商配置 → 添加供应商**。如果有 **启用供应商配置切换** 总开关，先打开。

| 字段 | 填什么 |
| --- | --- |
| 名称 | `Faro API` |
| 接入模式 | **纯 API** |
| Base URL | `https://faroapi.com/v1` |
| Key | 从 Faro 令牌管理复制的密钥 |

**无需认证** 保持关闭，**上游协议** 选 **Responses API**。其他选项先不用改。

<Accordion title="查看填写示例图">
  按 Codex++ v1.2.56 重建的字段示意，非实机截图；Key 和模型名需要换成自己的。
  <Frame><img src="/images/codex-plus-pure-api.png" alt="Codex++ 纯 API 填写示例：Base URL 为 https://faroapi.com/v1，填入 Key，再从上游获取模型" /></Frame>
</Accordion>

## 2. 获取模型，选中要用的名字

点击 **从上游获取**。

打开 [Faro 模型广场](https://faroapi.com/pricing)，看好供 Codex 使用的模型和价格，回到列表选择**一模一样的完整名字**，设为 **默认模型**。模型名后缀不要删。

如果获取失败，先核对地址和密钥；没有获取按钮的版本，可以复制模型广场中的完整名字填写。

## 3. 保存，并使用 Faro

点 **保存**，再点 Faro 卡片上的 **使用**。如果你在详情页，按钮叫 **设为当前**。

看到 **使用中**，就选好了。

## 4. 打开 Codex，开始使用

保存手头的任务，正常退出原来的桌面应用。回到管理工具的 **概览**，点 **启动 Codex++**，或使用安装后生成的 **Codex++** 入口。

**新建对话**，先发一句“你好”确认能回复；测试可能计费。想确认是否用了 Faro，可以查看 [使用日志](https://faroapi.com/console/log) 中有没有刚才的记录。

<Note>保留原配置，不要删除官方登录。请从 Codex++ 的入口启动，避免打开原版快捷方式后仍用旧配置；同一个工具先只用一个管理器配置。</Note>

用不了？看 [常见问题](/help/errors)。

本页对应 [BigPizzaV3/CodexPlusPlus v1.2.56](https://github.com/BigPizzaV3/CodexPlusPlus/releases/tag/v1.2.56)，其他版本按钮位置可能不同。
