## 不会操作？让 AI 一步步教你

把这页或对应教程发给你已经能用的 AI，比如豆包、ChatGPT。让它教你点哪里、填什么，不用先读懂所有内容。

<Prompt description="复制这段话，和教程一起发给 AI" actions={["copy"]}>
请按这份 Faro 教程带我配置。我是新手，先问我用 Windows 还是 Mac、用 Codex++ 还是 CC Switch。一次只教一步：在哪里点、填什么、应该看到什么，等我确认后再继续。按“填 Base URL 和 API Key→获取模型→对照 Faro 模型广场选择→保存并启用”的顺序来，不要让我写代码或编辑配置文件。密钥由我自己填，不要让我发给你；保留原来的配置。测试可能计费，先问我，再用一句短话确认能否正常回复。
</Prompt>

AI 打不开链接时，用本页上方的 **复制页面**，把正文发给它。密钥不要发给 AI 或群友。[查看详细说明](/start/ask-ai)。

## 第一步：准备地址和密钥

地址与 Faro 控制台中的 **API 信息** 一致：

| 线路 | 地址 | 什么时候填 |
| --- | --- | --- |
| 通用国内优化极速线路 | `https://faroapi.com/` | 配置 Claude Code 时使用 |
| GPT 专用线路 | `https://faroapi.com/v1` | 配置 Codex、Codex++ 时使用 |

**API Key** 在 [Faro → 令牌管理](https://faroapi.com/console/token) 中创建和复制。[不会创建？看这里](/start/api-key)。

## 第二步：打开你的 API 管理器

选你正在用的一个，不需要两个都装。

<CardGroup cols={2}>
  <Card title="CC Switch" icon="toggle-right" href="/tools/cc-switch">选择 Codex 或 Claude Code，填地址和密钥，再获取模型。</Card>
  <Card title="Codex++" icon="monitor" href="/tools/codex-plus">打开管理工具，添加 Faro，获取模型后保存使用。</Card>
</CardGroup>

还没安装？看 [下载与打开工具](/start/install-tools)。

## 第三步：获取模型，选好后使用

1. 在管理器里填好 **Base URL** 和 **API Key**。
2. 点击 **获取模型列表**；Codex++ 中叫 **从上游获取**。
3. 打开 [模型广场](https://faroapi.com/pricing)，看好想用的模型和价格，再回到列表选中**一模一样的名字**，后缀也保留。
4. 保存，再点 **启用** 或 **使用**。重新打开对应的 AI 工具，新建对话即可。

第一次只发一句短话确认能回复，测试也可能计费。遇到问题先看 [常见问题](/help/errors)，不用一上来重装软件。
