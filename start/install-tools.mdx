## 选一个管理器

| 你准备怎么用 | 从哪里下载 |
| --- | --- |
| 用 CC Switch 配置 Codex / Claude Code | [CC Switch 下载页](https://github.com/farion1231/cc-switch/releases) |
| 用 Codex++ 配置桌面应用 | [Codex++ 下载页](https://github.com/BigPizzaV3/CodexPlusPlus/releases) |

下载页里的 **Assets** 是安装文件。选与你电脑对应的 Windows 或 Mac 安装包，**不要选 Source code**。

Mac 打开苹果菜单 → **关于本机**：Apple 芯片选 arm64，Intel 选 x64。

## 还要安装 Codex / Claude Code 吗？

使用 **CC Switch**，还需要安装 Codex 或 Claude Code。

**Codex++** 也要按它的安装说明准备好对应的官方桌面应用；打开 **Codex++ 管理工具 → 概览**，确认能找到应用。

不会安装？把这页和电脑系统发给 AI，让它带你完成。

装好后回到 [CC Switch 教程](/tools/cc-switch) 或 [Codex++ 教程](/tools/codex-plus)，填地址和密钥即可。

<Accordion title="CC Switch 配好后，在哪里打开 Codex / Claude Code？">
如果你使用的是终端版，先在桌面新建一个空测试文件夹。在 VS Code 中点 **文件 → 打开文件夹** 选中它，再点 **终端 → 新建终端**。

使用 Codex 输入 `codex`；使用 Claude Code 输入 `claude`。看到输入框后，就可以发任务。没有 VS Code 或不知道怎么打开终端，把这一步交给 AI 教你即可。
</Accordion>
