---
title: "第一次使用：先让一句话跑通"
sidebarTitle: "第一次使用"
description: "先完成一次简短对话，确认能用，再交给 AI 做长任务。"
---

<Steps>
  <Step title="登录 Faro">
    打开 [Faro 网站](https://faroapi.com/)，注册或登录账号，然后进入控制台。网站密码用于登录；它不是 API 密钥。
  </Step>
  <Step title="看余额，再创建密钥">
    在「钱包管理」查看可用余额，按页面提示完成需要的充值。不要重复支付同一笔订单。

    打开 [令牌管理](https://faroapi.com/console/token)，创建一枚专供测试的令牌，例如命名为 `我的电脑测试`。给它设置你能接受的额度和有效期，再复制密钥。[查看创建步骤](/start/api-key)。
  </Step>
  <Step title="选一个模型">
    在 [模型广场](https://faroapi.com/pricing) 选择支持你所用工具的模型，复制完整模型 ID。先用默认参数，不要一开始就开最大上下文、最高思考强度或多个并行任务。
  </Step>
  <Step title="按你的工具填写">
    大多数人从 [CC Switch](/tools/cc-switch) 或 [Codex++](/tools/codex-plus) 开始。两者不是同一个软件，不要交叉复制配置。
  </Step>
  <Step title="发一句话，并查看日志">
    新建对话，发送：`只回复“连接成功”，不要调用工具。`

    收到回复后，打开 [使用日志](https://faroapi.com/console/log)，按时间、令牌和模型找到这次请求。收到回复且日志对应得上，才说明这次调用经过了 Faro。
  </Step>
</Steps>

<Warning>测试请求也可能计费。第一次只发一句短话；不要用真实客户资料、整份项目或长文档来测试。</Warning>

## 成功以后

可以开始正常使用。给不同软件分别创建令牌，之后就能看出哪个软件在消耗余额。遇到失败时保留错误信息，按 [报错说明](/help/errors) 排查；不要连续点击重试。
