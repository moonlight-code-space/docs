## 方式一：AI 讲，你来点

适合第一次接触 API、还不会改配置文件的情况。打开你已经能用的聊天 AI，把本页链接或相关教程正文发给它，再复制下面这段话。

<Prompt description="新手配置提示词" actions={["copy"]}>
请根据我附上的 Faro API 文档教我配置。我不熟悉 API，请先问我电脑系统、软件名称和版本，以及现在做到哪一步。一次只教一步，说明按钮在哪里、字段填什么、成功后看到什么；等我确认后再继续。CC Switch 只是配置管理工具，请先确认真正要用的客户端也已经安装。你不需要知道我的 API 密钥，告诉我在哪里填写即可。如果你打不开链接，请明确告诉我，把需要的章节列出来让我复制给你，不要猜文档内容。测试前先说明可能计费，征得我的确认后只用一句短话测试，并让我在 Faro 日志里确认。
</Prompt>

AI 打不开链接时，复制 [CC Switch](/tools/cc-switch) 或 [Codex++](/tools/codex-plus) 对应章节的正文发给它。截图只保留按钮和错误，先隐藏密钥及无关信息。

## 方式二：让能操作电脑的 Agent 帮你配置

这类 Agent 需要已经能够运行。它与普通网页聊天不同，可以在获得你的允许后检查文件或操作界面；不代表你要给它全部电脑权限。

<Prompt description="交给本机 Agent 的配置要求" actions={["copy"]}>
请按我提供的 Faro API 文档，帮助配置我指定的客户端。先确认软件名称、版本、电脑系统和现有供应商配置；不要擅自切换当前运行任务的模型。修改前备份需要改的文件，保留原有官方登录及其他供应商，只更改本次必要字段。真实密钥由我在本机安全输入，不要在对话、截图、日志、仓库或命令历史中显示或保存密钥。不要关闭沙箱或命令确认，不要伪造客户端身份。配置完成后先说明改了什么、如何恢复；说明测试可能计费，经我确认后只发一次短测试，并在 Faro 日志核对结果。无法验证的部分请明确写出来，不要把配置保存成功当作连接成功。
</Prompt>

## 你仍然需要自己确认的事

1. 下载的客户端来自哪个项目，是否就是你要用的软件。
2. 密钥填进了哪里，是否给令牌设置了合适额度。
3. 最后是否真的收到了回答，以及 Faro 日志中是否有对应请求。

AI 可能看错截图或给出旧版本操作。如果它说的按钮不存在，告诉它实际软件版本并提供不含密钥的截图，不要为了对上教程随便删除配置。
