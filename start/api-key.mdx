## 去哪里创建

登录后打开 [控制台 → 令牌管理](https://faroapi.com/console/token)，选择添加令牌。页面里叫「令牌」，其他软件里通常叫「API Key」，这里说的是同一份调用凭证。

| 设置项 | 第一次建议怎么填 |
| --- | --- |
| 名称 | 按设备或软件区分，如 `家里电脑-Claude` |
| 额度 | 先给一个能接受的测试额度，不必直接设为无限 |
| 过期时间 | 按实际用途设置；临时测试用完就停用 |
| 分组 | 按模型说明选择，价格和可用模型可能不同；拿不准时先确认模型所在分组，不要为排错随便放开全部权限 |
| 模型限制 | 如果启用，记得把准备调用的完整模型名加入允许列表 |
| IP 限制 | 只有确定出口 IP 并理解限制时再设置，否则可能把自己挡住 |

保存后复制完整密钥，填入客户端的 API Key 一栏。不要多复制空格、引号或换行，也不要把网站登录密码填进去。

## 不要这样分享密钥

- 不要发到群聊、客服截图或公开仓库。
- 不要把密钥放在网页前端代码里，浏览器中的代码可能被访问者读到。
- 不要把配置文件直接上传给别人；先移除 API Key、Cookie 和登录令牌。

## 怀疑密钥泄露了

先在令牌管理停用泄露的令牌，再新建一枚、更新客户端。检查这段时间的使用日志。改网站密码不等于撤销 API 密钥。

<Tip>一台设备或一个软件用一枚令牌。既方便看用量，也方便只停用出问题的那一枚。</Tip>
