---
title: "创建 API Key"
sidebarTitle: "创建 API Key"
description: "在 Faro 复制密钥，填到管理器里。"
---

1. 登录 [Faro](https://faroapi.com/)，进入 [控制台 → 令牌管理](https://faroapi.com/console/token)。
2. 点击添加令牌，起个好认的名字，例如 `我的电脑`。
3. 设置可用额度和有效期，然后保存。
4. 复制密钥，粘贴到 CC Switch 的 **API Key** 或 Codex++ 的 **Key**。

**密钥不要发给别人或 AI。** 如果泄露，到令牌管理停用并重新创建。

接下来选你的管理器：[CC Switch](/tools/cc-switch) · [Codex++](/tools/codex-plus)。

如果提示余额不足，查看 [充值与用量](/account/wallet)。
