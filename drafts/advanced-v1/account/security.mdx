## 只把密钥填进你信任的软件

从项目官方发布页下载客户端，核对作者和仓库地址。不要把密钥填进来历不明的「配置检测」网页；也不要把登录 Cookie 当作 API Key 使用。

## 配置工具前备份旧设置

CC Switch、Codex++ 和官方 Codex 可能读写相同目录里的配置。先保留原供应商，确认当前任务已经结束，再切换。不要为了接入 Faro 删除全部登录数据。

## 让 AI 改配置，也要限定范围

告诉它只配置指定软件，先备份，密钥由你在本机安全输入，不要写入仓库、截图或对话。连接确认后再授权读取项目文件；没必要为了测试关闭所有命令确认或沙箱。

## 敏感内容不要拿来测试

首次连接只发一句普通问候。不要使用客户资料、身份证件、生产密码或未获授权的代码。使用模型时也需要遵守相关服务的使用规则；出现策略限制时，按错误说明处理，不要伪造客户端身份规避限制。
