## 充值后在哪里确认

打开 [钱包管理](https://faroapi.com/console/topup)，查看账户余额和充值账单。充值优惠、应付金额和到账额度以付款前页面显示为准。

如果已经扣款但余额没变，先刷新钱包和账单，核对订单状态。仍未到账时联系支持，提供订单号、付款时间和金额；不要把支付密码或完整付款账户发出来。

## 余额够，为什么还提示额度不足？

账号余额和令牌额度是两道限制。账号有余额，但当前令牌用完额度、已过期或被停用，仍然无法调用。到「令牌管理」检查正在使用的那一枚。

## 页面上的美元符号怎么理解？

Faro 的模型面板和余额中，`$` 用作站内显示单位，不代表你要额外按美元汇率付款。站内基础口径是人民币 1 元充值对应 1 个显示额度单位；实际充值优惠、赠送或折扣以结算页面为准。

厂商官方 API 的美元报价、Faro 站内价格、实际付款金额要分开看，不要直接拿显示符号判断成本。

## 联盟余额和 API 钱包一样吗？

不是。联盟佣金有单独的记录与使用规则。划转、提现的门槛、状态和可用金额以联盟中心当前页面为准；提交申请不代表已经到账。不要重复提交来尝试绕过限制。

<Note>AI 代充商店购买的会员、Open Study 服务与 Faro API 钱包分别结算，不会因为一个地方购买成功就自动给另一个地方增加余额。</Note>
