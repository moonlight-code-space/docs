## 去哪里充值？

打开 [钱包管理](https://faroapi.com/console/topup)，选择金额并付款。

已经扣款但没到账？先刷新钱包和账单，仍没有就 [联系支持](/help/contact)，不要再付一遍。

## 为什么余额够，还说额度不足？

除了账户余额，正在使用的那枚 API Key 也有自己的额度和有效期。到 [令牌管理](https://faroapi.com/console/token) 检查一下。

## 去哪里看花了多少钱？

打开 [使用日志](https://faroapi.com/console/log)，能看到模型、时间和每次花费。选择模型前，在 [模型广场](https://faroapi.com/pricing) 查看价格。

<Accordion title="页面上的 $ 是美元吗？">
Faro 余额和模型面板中的 `$` 是站内显示单位，不需要再乘美元汇率。人民币 1 元对应 1 个基础显示额度单位，实际优惠和到账额度以付款页面为准。
</Accordion>
